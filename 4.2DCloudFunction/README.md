# Task 5.3D – Calling a Function from the Web

## Description

This project demonstrates remote light control using:

- HTML Front-End
- Node.js Backend
- MQTT Communication
- Arduino Nano 33 IoT

## Hardware

- Arduino Nano 33 IoT
- Breadboard
- 3 LEDs
- 3 Resistors
- Jumper Wires

## Room Connections

- Living Room → D2
- Bathroom → D3
- Closet → D4

## System Flow

Carer → HTML Web Page → Node.js Backend → MQTT Broker → Arduino Nano 33 IoT → toggleLight(String room) → LEDs

## Technologies Used

- HTML
- JavaScript
- Node.js
- Express
- MQTT
- WiFiNINA
- PubSubClient
